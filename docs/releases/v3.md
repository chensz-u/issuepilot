# IssuePilot V3

V3 extends the durable V2 workflow with bounded source inspection and an evidence-linked verification plan.

- `inspect_source_code` reads repository metadata and the default-branch tree, then fetches at most three query-relevant immutable Git blob SHAs with encoded and decoded 200 KB limits.
- Absolute paths, `..` segments, unsupported suffixes, and oversized blobs are rejected before a contents request.
- The graph now records `validate → tools → hypothesize → plan → synthesize → approval`.
- Plans contain argv arrays for human execution; IssuePilot still runs no repository command and writes nothing to GitHub.
- The seven-metric fixture contains source evidence plus distractors and requires exact plan-to-supported-evidence grounding.

Verified live against `chenyi-c/issuepilot`: the source tool returned three bounded Python artifacts for an investigation/checkpoint query. This is a connectivity smoke test, not an accuracy claim.
