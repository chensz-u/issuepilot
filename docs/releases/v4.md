# IssuePilot V4

V4 is the portfolio closeout release.

- A deterministic quality policy reports supported/rejected evidence, tool errors, three named checks, review risk, and whether approval is allowed.
- Batch intake accepts one to five requests, validates all repository names before starting work, and returns independent durable investigations.
- Audit export creates a byte-stable ZIP containing canonical `investigation.json`, ordered `events.json`, and a `manifest.json` with SHA-256 hashes.
- The eight-metric regression fixture checks the expected risk policy in addition to source relevance, plan grounding, citations, trajectory, and approval safety.

Boundaries remain deliberate: quality risk is a transparent deterministic policy, not a probability or production accuracy estimate; batches are bounded and sequential to protect GitHub API budgets. Audit exports contain the user-supplied title/body plus bounded, token-redacted GitHub previews, and the manifest marks this explicitly; review the bundle before sharing it.
